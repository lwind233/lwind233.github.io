用一个普通栈保存元素，同时让每个入栈元素额外记录“它入栈之前栈中的最小值”，并用一个全局变量 min 表示当前栈内最小值；这样 push 时先把当前值和旧的最小值一起压栈，再更新全局最小值，pop 时弹出栈顶元素后，直接把全局最小值恢复成这个元素里保存的旧最小值，top 直接看栈顶元素的值，getMin 直接返回全局最小值，因此四个操作都能在 O(1) 时间内完成，本质上就是把“历史最小值”跟着每个元素一起存起来，这样出栈时就能无条件恢复到上一状态。

```java
class MinStack {
    int min=Integer.MAX_VALUE;
    Stack<Tmp> s;

    class Tmp{
        int val;
        int min;
        Tmp(int val,int min){
            this.val = val;
            this.min = min;
        }
    }

    public MinStack() {
        s = new Stack<Tmp>();
    }
    
    public void push(int val) {
        this.s.push(new Tmp(val,this.min));
        this.min = Math.min(val,this.min);
        
    }
    
    public void pop() {
        Tmp tmp = this.s.pop();
        this.min = tmp.min;
    }
    
    public int top() {
        return this.s.peek().val;
    }
    
    public int getMin() {
        return this.min;
    }
}
```
