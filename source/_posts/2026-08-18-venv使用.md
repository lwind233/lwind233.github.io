### 新建环境
```powershell
python -m venv .venv
```
将环境目录设置为.venv，目录结构大致为

```
.venv/
├── Lib/
│   └── site-packages/   # 第三方依赖
├── Scripts/
│   ├── python.exe       # 虚拟环境 Python
│   ├── pip.exe
│   └── Activate.ps1
└── pyvenv.cfg           # 基础 Python 信息
```
### 虚拟环境使用
激活虚拟环境
```powershell
.\.venv\Scripts\Activate.ps1
```
终端会显示
```
(.venv) PS D:\project>
```
此时python、pip、pytest会指向.venv中的程序

安装依赖
```
python -m pip install 包名
```
不直接用pip可以保证用虚拟环境的pip
