把“到第 i 阶楼梯的方法数”看成一个状态 dp[i]：走到第 i 阶时，最后一步要么是从 i-1 跨 1 阶上来，要么是从 i-2 跨 2 阶上来，所以有转移方程 dp[i] = dp[i-1] + dp[i-2]。初始条件是 dp[1] = 1，dp[2] = 2。因此这题本质上是一个斐波那契型的动态规划问题；如果再优化空间，只需要用两个变量滚动保存前两项即可，把空间复杂度降到 O(1)。

```java
class Solution {
    public int climbStairs(int n) {
        if(n==1) return 1;

        int[] dp = new int[n];
        dp[0]=1;
        dp[1]=2;

        for(int i=2;i<=n-1;i++){
            dp[i] = dp[i-1]+dp[i-2];
        }

        return dp[n-1];
    }
}
```
