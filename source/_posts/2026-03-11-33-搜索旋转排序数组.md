## 最传统二分

先二分查找突变点，然后对两侧进行两次二分（或者比较target和两侧有序数组的边界进行一次二分）即可

```java
class Solution {
    public int search(int[] nums, int target) {
        int left=0;
        int right = nums.length-1;
        int idx=nums.length-1;
        while(left<=right){
            int mid = left+(right-left)/2;
            if(mid==nums.length-1 || nums[mid]>nums[mid+1]){
                idx = mid;
                break;
            }else if(nums[mid]>=nums[0]) left = mid+1;
            else if(nums[mid]<=nums[nums.length-1]) right = mid-1;
        }

        left = 0;
        right = idx;
        while(left<=right){
            int mid = left+(right-left)/2;
            if(nums[mid]==target) return mid;
            else if(nums[mid]>target) right = mid-1;
            else left = mid+1;
        }

        left = idx+1;
        right = nums.length-1;
        while(left<=right){
            int mid = left+(right-left)/2;
            if(nums[mid]==target) return mid;
            else if(nums[mid]>target) right = mid-1;
            else left = mid+1;
        }

        return -1;
    }
}
```

## 高级二分

每次取中值后，可以根据nums[mid]与当前左右边界的大小关系判断当前哪一边是有序数组，哪一边是无序数组，如果target在有序数组里，直接把左右边界缩小到有序数组里即可，否则继续缩小无序数组和有序数组混合的部分，直到左右指针反超查询失败

```java
class Solution {
    public int search(int[] nums, int target) {
        int left=0;
        int right = nums.length-1;
        int leftB = nums[0];
        int rightB = nums[right];
        
        while(left<=right){
            int mid = left+(right-left)/2;
            if(nums[mid]==target) return mid;

            if(nums[mid]>=nums[left]){
                if(target>=nums[left] && target<=nums[mid]){
                    right = mid-1;
                }
                else left = mid+1;
            }else if(nums[mid]<=nums[right]){
                if(target<=nums[right] && target>=nums[mid]){
                    left = mid+1;
                }
                else right = mid-1;
            }
        }
        return -1;

    }
}
```
