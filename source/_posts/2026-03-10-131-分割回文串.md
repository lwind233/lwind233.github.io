## 纯回溯

加入到路径里的只能是字符串，那就先把当前位置到末尾的所有可能的回文字符串挨个加到结尾里，进入下一层遍历，下一层遍历从当前遍历到的下标的下一位开始。

```java
class Solution {
    List<String> path = new LinkedList<>();
    List<List<String>> result = new ArrayList<>();


    public List<List<String>> partition(String s) {
        traceBack(s,0);
        return result;
    }

    public void traceBack(String s, int st){
        if(st==s.length()){
            result.add(new ArrayList<>(path));
            return;
        }
        for(int i=st;i<=s.length()-1;i++){
            String tmp = s.substring(st,i+1);
            if(match(tmp)){
                path.add(tmp);
                traceBack(s,i+1);
                path.removeLast();
            }
        }
    }

    public boolean match(String s){
        for(int i=0;i<=s.length()-1;i++){
            if(s.charAt(i)!=s.charAt(s.length()-1-i)) return false;
            if(i>s.length()-1-i) return true;
        }
        return true;
    }
}
```

当然也可以选择从字符角度考虑，每个字符都可以选择加入当前的临时字符串里。而当先前的临时字符串本身就是回文字符串时，这个字符就可以选择作为新字符串的开头。
