先遍历一遍字符串，记录每个字符最后一次出现的位置；再从左到右扫描，用 `maxIdx` 维护当前片段内所有字符的最远结束位置，每遇到一个字符就用它的最后出现位置更新 `maxIdx`。如果扫描到的位置 `i` 恰好等于 `maxIdx`，说明当前片段中的所有字符都已经被完整包含，不会再出现在后面，此时就可以把这一段切分出来。这个做法本质上是**贪心**：让当前片段尽量在最早能结束的位置结束。

```
class Solution {
    public List<Integer> partitionLabels(String s) {
        Map<Integer,Integer> cIdx = new HashMap<>();

        for(int i=0;i<=s.length()-1;i++){
            int c = s.charAt(i);
            cIdx.put(c,i);
        }

        List<Integer> result = new ArrayList<>();
        int maxIdx=-1;
        int now = -1;

        for(int i=0;i<=s.length()-1;i++){
            int c = s.charAt(i);
            maxIdx = Math.max(cIdx.get(c),maxIdx);
            
            if(maxIdx==i){
                result.add(i-now);
                now = i;
            }
        }

        return result;

    }
}
```
