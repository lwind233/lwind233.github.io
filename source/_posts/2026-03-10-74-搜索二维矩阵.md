就是最基本的二分，把mid的坐标进行一下映射，对二维矩阵的行长度进行取模和取余即可

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int m = matrix.length;
        int n = matrix[0].length;
        int left=0;
        int right = m*n-1;
        while(left<=right){
            int mid = (left+right)/2;
            int idxI = mid / n;
            int idxJ = mid % n;
            if(matrix[idxI][idxJ]==target) return true; 
            else if(matrix[idxI][idxJ]<target) left = mid+1;
            else right = mid-1;
        }

        return false;
    }
}
```
