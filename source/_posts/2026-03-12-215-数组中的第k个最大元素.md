这题可以用快速选择解决，核心思想是不必把整个数组排好序，只需要不断缩小目标元素所在的区间。对于第 k 大元素，可以先转换成“升序排序后下标为 n-k 的元素”。每一轮随机选择一个 pivot，然后对当前区间做三路划分：把数组分成 < pivot、== pivot、> pivot 三部分。划分完成后，如果目标下标落在中间这段 == pivot 的区间里，说明答案已经确定，直接返回；如果目标下标在左边，就继续去左半部分找；如果在右边，就继续去右半部分找。三路划分相比普通 partition 的优势在于，遇到大量重复元素时，可以一次性把所有等于 pivot 的元素归到中间，避免反复递归相同数字导致退化，因此这版写法比普通二路划分更稳。平均时间复杂度是 O(n)，空间复杂度是 O(1)。

```java
class Solution {
    private final Random random = new Random();

    public int findKthLargest(int[] nums, int k) {
        int left = 0;
        int right = nums.length-1;
        int target = nums.length-k;

        while(left<=right){
            int pivotIndex = left + random.nextInt(right - left + 1);
            int p = nums[pivotIndex];

            int lB = left;
            int rB = right;
            int i = left;

            while(i<=rB){
                if(nums[i]<p){
                    swap(nums,lB,i);
                    lB++;
                    i++;
                }else if(nums[i]>p){
                    swap(nums,rB,i);
                    rB--;
                }else{
                    i++;
                }
            }

            if(lB<=target && target<=rB) return nums[target];
            else if(target<lB) right = lB-1;
            else if(target>rB) left = rB+1;
        }

        return -1;
    }

    public void swap(int[] nums, int a, int b){
        int tmp = nums[a];
        nums[a] = nums[b];
        nums[b] = tmp;
    }
}
```
