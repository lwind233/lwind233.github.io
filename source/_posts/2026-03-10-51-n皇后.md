N皇后的难点就在于想明白皇后的攻击范围该怎么表示

实际上可以用四个数组表示，row代表皇后可以攻击的每一行，col代表皇后可以攻击的每一列，slash1和slash2分别代表皇后可以攻击的两个斜线。

对i，j位置的皇后，可以发现，其能攻击第i行、第i列。可以攻击经过i+j的斜线，也可以攻击经过j-i的斜线

因此用四个数组就可以表示当前位置是否可以放皇后，如果按行或按列遍历，就可以少用一个数组。


```java
class Solution {
    int[][] pan;
    int[] col;
    int[] slash1;
    int[] slash2;
    int count=0;
    List<List<String>> result = new ArrayList<>();

    public List<List<String>> solveNQueens(int n) {
        col = new int[n];
        slash1 = new int[n*2-1];
        slash2 = new int[n*2-1];
        pan = new int[n][n];
        traceBack(n,0);
        return result;
    }

    void traceBack(int n, int i){
        if(count==n){
            translate(n);
            return;
        }
        for(int j=0;j<=n-1;j++){
            if(col[j]==0 && slash1[i+j]==0 && slash2[j-i+n-1]==0){
                col[j]=1;
                slash1[i+j]=1;
                slash2[j-i+n-1]=1;
                pan[i][j]=1;
                count++;
                traceBack(n,i+1);
                count--;
                pan[i][j]=0;
                col[j]=0;
                slash1[i+j]=0;
                slash2[j-i+n-1]=0;
            }
        }
    }

    void translate(int n){
        List<String> tmp = new ArrayList<>();
        for(int i=0;i<=n-1;i++){
            StringBuilder sb = new StringBuilder();
            for(int j=0;j<=n-1;j++){
                if(pan[i][j]==0) sb.append('.');
                else sb.append('Q');
            }
            tmp.add(sb.toString());
        }
        result.add(new ArrayList(tmp));
    }
}
```
