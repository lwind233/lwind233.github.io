70 爬楼梯

发表于 2026-03-31 分类于 题解 ， hot100
本文字数： 396 阅读时长 ≈ 1 分钟

把“到第 i 阶楼梯的方法数”看成一个状态 dp[i]：走到第 i 阶时，最后一步要么是从 i-1 跨 1 阶上来，要么是从 i-2 跨 2 阶上来，所以有转移方程 dp[i] = dp[i-1] + dp[i-2]。初始条件是 dp[1] = 1，dp[2] = 2。因此这题本质上是一个斐波那契型的动态规划问题；如果再优化空间，只需要用两个变量滚动保存前两项即可，把空间复杂度降到 O(1)。

763 划分字母区间

发表于 2026-03-31 分类于 题解 ， hot100
本文字数： 672 阅读时长 ≈ 1 分钟

先遍历一遍字符串，记录每个字符最后一次出现的位置；再从左到右扫描，用 maxIdx 维护当前片段内所有字符的最远结束位置，每遇到一个字符就用它的最后出现位置更新 maxIdx。如果扫描到的位置 i 恰好等于 maxIdx，说明当前片段中的所有字符都已经被完整包含，不会再出现在后面，此时就可以把这一段切分出来。这个做法本质上是贪心：让当前片段尽量在最早能结束的位置结束。

45 跳跃游戏II

发表于 2026-03-12 更新于 2026-03-31 分类于 题解 ， hot100
本文字数： 585 阅读时长 ≈ 1 分钟

这题的最优做法是贪心。核心思路是把每一次跳跃看成一层一层向前推进：max 表示当前跳跃次数下能够到达的最远边界，tmpMax 表示在当前这层范围内再多跳一步最远可以到哪里。遍历数组时，只要下标还在当前边界 max 内，就不断用 tmpMax = Math.max(tmpMax, i + nums[i]) 更新下一层的最远位置；一旦遍历位置超过了当前边界，说明必须再跳一步了，此时把步数加一，并把当前边界更新为 tmpMax。这样每次都在当前可达范围内选择“下一步能扩得最远的位置”，最终用最少的跳跃次数到达终点。这个做法的时间复杂度是 O(n)，空间复杂度是 O(1)。

55 跳跃游戏

发表于 2026-03-12 更新于 2026-03-31 分类于 题解 ， hot100
本文字数： 468 阅读时长 ≈ 1 分钟

动规题解：这题可以定义 dp[i] 表示是否能够到达下标 i。初始状态 dp[0]=true，因为一开始就在第一个位置。对于每个位置 i，去枚举前面的所有位置 j，如果 j 本身可达，并且从 j 出发最远能够跳到 i 或更远，也就是 dp[j]==true && j+nums[j]>=i，那么就说明 i 也可达，令 dp[i]=true。最后只要看 dp[n-1] 是否为 true 即可。这个做法的本质是从前往后判断每个位置能不能由前面的可达位置跳过来，时间复杂度 O(n^2)，空间复杂度 O(n)。

贪心题解：这题更优的做法是贪心，核心是维护当前位置之前能够到达的最远下标 max。从左到右遍历数组时，如果当前位置 i 不超过 max，说明这个位置可达，那么就可以继续用 max = Math.max(max, i + nums[i]) 更新当前能到达的最远范围；如果某个位置已经大于 max，说明这个位置根本到不了，后面也不用再看了。遍历结束后，只要 max >= n-1，就说明能够到达最后一个位置。这个做法的本质是不断扩大可到达区间，时间复杂度 O(n)，空间复杂度 O(1)。

121 买卖股票最佳时机

发表于 2026-03-12 更新于 2026-03-31 分类于 动态规划
本文字数： 428 阅读时长 ≈ 1 分钟

这题可以用动态规划来理解：定义 dp[i][0] 表示第 i 天结束时手里没有股票时的最大利润，dp[i][1] 表示第 i 天结束时手里持有股票时的最大利润。初始时，第 0 天不持有股票的利润是 0，持有股票的利润是 -prices[0]。之后每天更新两种状态：如果第 i 天结束时不持有股票，要么昨天就不持有，今天什么都不做，要么昨天持有，今天把股票卖出，所以有 dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])；如果第 i 天结束时持有股票，要么昨天就持有，今天不操作，要么今天才第一次买入，因为这题只允许一次交易，所以不能写成“之前赚了钱再买”，只能是直接买入，因此有 dp[i][1] = max(dp[i-1][1], -prices[i])。最终答案就是最后一天不持有股票时的最大利润 dp[n-1][0]。本质上，这道题就是一边维护历史最低买入价，一边维护当前最大利润，时间复杂度 O(n)，空间复杂度 O(n)，并且可以进一步压缩到 O(1)。

215 数组中的第k个最大元素

发表于 2026-03-12 更新于 2026-03-31 分类于 题解 ， hot100
本文字数： 1.1k 阅读时长 ≈ 1 分钟

这题可以用快速选择解决，核心思想是不必把整个数组排好序，只需要不断缩小目标元素所在的区间。对于第 k 大元素，可以先转换成“升序排序后下标为 n-k 的元素”。每一轮随机选择一个 pivot，然后对当前区间做三路划分：把数组分成 < pivot、== pivot、> pivot 三部分。划分完成后，如果目标下标落在中间这段 == pivot 的区间里，说明答案已经确定，直接返回；如果目标下标在左边，就继续去左半部分找；如果在右边，就继续去右半部分找。三路划分相比普通 partition 的优势在于，遇到大量重复元素时，可以一次性把所有等于 pivot 的元素归到中间，避免反复递归相同数字导致退化，因此这版写法比普通二路划分更稳。平均时间复杂度是 O(n)，空间复杂度是 O(1)。

155 最小栈

发表于 2026-03-12 更新于 2026-03-31 分类于 题解 ， hot100
本文字数： 749 阅读时长 ≈ 1 分钟

用一个普通栈保存元素，同时让每个入栈元素额外记录“它入栈之前栈中的最小值”，并用一个全局变量 min 表示当前栈内最小值；这样 push 时先把当前值和旧的最小值一起压栈，再更新全局最小值，pop 时弹出栈顶元素后，直接把全局最小值恢复成这个元素里保存的旧最小值，top 直接看栈顶元素的值，getMin 直接返回全局最小值，因此四个操作都能在 O(1) 时间内完成，本质上就是把“历史最小值”跟着每个元素一起存起来，这样出栈时就能无条件恢复到上一状态。
